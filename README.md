# Snow Stunt 2

Snowboard-Stunt-Spiel für den Browser (iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“).

**Spielen:** https://tomwenn.github.io/snow-stunt/

- Handy neigen = drehen / Flips
- Nach oben wischen = Springen, nach unten wischen = Ducken
- Linke / rechte Bildschirmhälfte halten = Tailgrab / Nosegrab (beide = Indy)

Quellcode in `source/` (Build: `npm install && node build.js pwa`).
